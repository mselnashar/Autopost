Autopost — أقوال

بوت نشر تلقائي لصفحة فيسبوك، مبني على Cloudflare Workers مع قاعدة بيانات D1،
يتولّد المحتوى عبر Gemini AI ويختار صورة من Wikimedia Commons مع ذكر المصدر والترخيص.

المزايا

- نشر تلقائي كل 4 ساعات بتوقيت القاهرة (10:00، 14:00، 18:00، 22:00، 02:00، 06:00)
- توليد منشورات قصيرة (40–80 كلمة) بمواضيع تاريخية وثقافية متنوعة دون تكرار آخر 30 موضوعاً
- صورة مرتبطة بالموضوع من Wikimedia Commons مع الإسناد (المصدر/الصاحب/الترخيص)
- لوحة تحكم عربية: إنشاء محتوى بالذكاء الاصطناعي، مسودات، معاينة، نشر مباشر، سجل المحاولات
- تتبع كامل للحالات في جداول `posts` و `publish_logs` و `auto_runs`

الإعداد

```bash
npm install -g wrangler
wrangler login

# المفاتيح السرية
wrangler secret put ADMIN_KEY          # مفتاح لوحة التحكم
wrangler secret put GEMINI_API_KEY     # مفتاح Gemini API
wrangler secret put PAGE_ACCESS_TOKEN  # توكن صفحة فيسبوك

# قاعدة البيانات (مرة واحدة)
wrangler d1 create aqwal-database
# ثم انسخ database_id إلى wrangler.jsonc

wrangler deploy
```

متغيرات اختيارية

المتغير	الوصف	
`FB_PAGE_ID`	رقم الصفحة (افتراضياً مضبوط داخل الكود)
`WIKI_CONTACT`	بريدك الحقيقي لطلبات Wikimedia Commons — مهم: بدونه قد تُرفض طلبات الصور (يظهر تنبيه في السجلات ولوحة التحكم)
`AUTO_DRAFT`	عند ضبطه على `1` تُحفظ المنشورات التلقائية كمسودات بانتظار الموافقة من لوحة التحكم بدل النشر المباشر (الافتراضي: النشر المباشر)	
`GEMINI_MODEL`	نموذج Gemini (افتراضياً `gemini-3.5-flash-lite`)	

النشر على منصات إضافية (اختياري)

كل منصة خلف مفتاح تفعيل من لوحة التحكم (الإعدادات ← النشر على منصات أخرى)، ولا تُنشر إلا بعد ضبط مفاتيحها:

المنصة	المطلوب	
إنستغرام	`wrangler secret put IG_BUSINESS_ID` — معرّف حساب إنستغرام للأعمال المربوط بالصفحة، وصلاحيتا `instagram_basic` و`instagram_content_publish` على توكن الصفحة. يتطلب صورة دائماً	
قناة تيليجرام	`wrangler secret put TELEGRAM_CHANNEL_ID` — معرّف القناة (@name أو -100…)، والبوت مشرف فيها	
إكس	`wrangler secret put` لكل من `X_API_KEY` و`X_API_SECRET` و`X_ACCESS_TOKEN` و`X_ACCESS_SECRET` من لوحة مطوري X	

فشل أي منصة إضافية لا يوقف النشر على فيسبوك؛ تظهر النتيجة في سجل المحاولات (عمود `platforms` في `publish_logs`).

ملاحظات

- النشر التلقائي متوقف افتراضياً — فعّله من لوحة التحكم.
- الجداول تُنشأ تلقائياً عند أول تشغيل (`posts`, `publish_logs`, `auto_settings`, `auto_topics`, `auto_runs`).
- جدول `wrangler.jsonc` يشغّل cron كل ساعة؛ يتحقق العامل من ساعة القاهرة وينشر فقط في المواعيد الستة (تحقق مقاوم لأي انزياح توقيت).
- لوحة التحكم في `app.js` تُحمَّل عبر jsDelivr مثبّتة على وسم الإصدار `v1.0.0` من هذا المستودع — عند تعديل `app.js` أنشئ إصداراً (Release) جديداً وحدّث الوسم في رابط jsDelivr داخل `src/dashboard.js` حتى لا تصل التعديلات مباشرة للوحة المنشورة.
- مهام النشر التلقائي تمر عبر قائمة انتظار Cloudflare Queues (`aqwal-publish-jobs`): الكرون كل ساعة يضع مهمة في القائمة ومستهلك القائمة ينفذها، مع إعادة محاولة آمنة (مفتاح الموعد فريد في `auto_runs`). إن لم تكن القائمة مربوطة يعمل النشر مباشرة من الكرون كالسابق.

بنية المشروع

```
src/
  index.js       نقطة الدخول: الكرون، مستهلك القائمة، وتوجيه HTTP
  api.js         واجهات API للوحة التحكم (محمية بمفتاح ADMIN_KEY)
  dashboard.js   صفحة لوحة التحكم المضمّنة
  auto.js        دورة النشر التلقائي واختيار الموضوع
  generation.js  توليد المنشورات والمقالات عبر Gemini
  gemini.js      استدعاء Gemini مع إعادة المحاولة والنموذج البديل
  images.js      البحث عن الصور في Wikimedia Commons والتحقق من التراخيص
  facebook.js    النشر على فيسبوك: منشورات وقصص وريلز
  blog.js        النشر على Blogger
  notify.js      تنبيهات تيليجرام
  db.js          إنشاء الجداول وترقيع الأعمدة
  time.js        توقيت القاهرة ومواعيد النشر
  config.js      الثوابت والأدوات المشتركة
```
